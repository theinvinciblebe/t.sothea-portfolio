## ✨ What's New in V2

- 🎨 **Redesigned Luxury Palette:** Curated modern color scheme pairing warm linen (**`#F8F0E5`**) with deep forest green (**`#1C352D`**) accents for a high-end editorial feel.
- 🌗 **Advanced Dual-Theme Engine:** Seamless Light & Dark mode toggle featuring smooth View Transitions ripple animation and persistent `localStorage` preference.
- 🌐 **Bilingual Localization (EN & KH):** Instant runtime translation between English and Khmer (ភាសាខ្មែរ) with typography optimized for Kantumruy Pro.
- 🖱️ **Interactive Custom Cursor:** Fluid magnetic cursor follower, interactive hover scaling, and click ripple effects.
- 📱 **Touch-Ready Swiper Carousel:** Interactive project showcases with technology badges, live preview buttons, and direct repository links.
- ⚡ **Optimized Performance:** Clean zero-framework architecture using modern HTML5, CSS3 Custom Properties, and vanilla ES6+ JavaScript.

## 💻 Local Setup & Development

To preview and run this portfolio locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/theinvinciblebe/t.sothea-portfolio.git
   cd t.sothea-portfolio
   ```

2. **Open in your browser:**
   - Double-click `index.html` to open it directly in any modern browser, or
   - Use VS Code **Live Server** extension, or
   - Run a simple local server:
     ```bash
     # Using Python
     python -m http.server 8000
     ```
     Navigate to `http://localhost:8000`.
